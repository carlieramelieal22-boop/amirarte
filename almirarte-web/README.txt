ALMIRARTE – THE ART OF GIFTING
Proyecto web para evidencia GA7-220501102-AA1-EV01

CÓMO EJECUTAR
1. Descomprime la carpeta almirarte-web.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en un navegador. También puedes usar la extensión Live Server.
4. Revisa que haya conexión a internet para cargar las tipografías de Google Fonts.

ESTRUCTURA
index.html: estructura semántica de la página.
css/variables.css: colores y variables globales.
css/layout.css: distribución y diseño adaptable.
css/components.css: botones, tarjetas, modal y controles.
js/navigation.js: menú móvil, menú desplegable y año del footer.
js/carousel.js: controles del carrusel.
js/customizer-modal.js: formulario de personalización y carrito de demostración.
assets/: imágenes de referencia y fotografías de productos.

NOTAS IMPORTANTES
- Los precios son valores demostrativos y deben confirmarse con el negocio.
- El botón de WhatsApp usa un enlace genérico. Antes de publicar, reemplaza wa.me/ por wa.me/57 seguido del número real, sin espacios ni signos.
- El carrito es demostrativo y funciona durante la sesión del navegador; no procesa pagos ni almacena pedidos en un servidor.
- Sustituye las imágenes de referencia por fotografías oficiales de AlmirArte cuando estén disponibles.
